## PART I — THE TRANSFORMATION (what actually happened, and the thesis it proved)

The operation crossed from v1 to v2 in roughly one week, and the crossing was not a refactor — it was a philosophical inversion. v1 was a compiler chain: CSV + canon → csv2script → a compiled .md/.thumb pair → parse_script → beats JSON → recreation_pipeline legs, with prose-and-directive files as the interchange format, a 12-act ROMAN ceiling, tag-word parser traps (Law 25's whole bug class), per-video config drift, and knowledge scattered across "1000s of lines" that had to be re-read to be trusted. v2 replaced the interchange format with a DATABASE and the philosophy with one sentence: **the data is the design; the plumbing is dumb.** A film is now a folder of seven small data files (the src set) fed through one door (ingest) into one SQLite db per project, rendered by six idempotent stages that read columns and config and contain no story knowledge whatsoever. Every creative decision — pacing, motion, animation spend, placement, period, cast, effects — is a cell value or a config key. Every mechanism that used to be a code path is now a column the machine obeys. The consequences compounded immediately: the ROMAN ceiling died (blocks are just rows), the tag-word class died by construction (no prose/directive ambiguity), config drift died (channel.json is the door-read single source), the multi-product future arrived pre-built (the EDL table sat in the schema waiting for Option C), and — the deepest one — **the operation's brain moved out of code and into artifacts**, which is why the senior line survived a model downgrade mid-week without a visible seam.

The week's arc, compressed: the FLAGSHIP ("The Complete Story of the Bible — Including the Books They Burned", 735 beats, 29,244 words, 3:19:33, ~$100, rendered unattended overnight in one tmux chain) was v2's shakedown cruise and paid for seven laws (29–35) inside three Studio sessions; the MONTAGE33 harvest proved provided-stills and the born-at-measured-length guard; the OPERATOR KIT (v2.1 → v2.1.8) turned the process into a portable briefcase a cheaper model runs; the CASTING SYSTEM (protocol + fal Assets + the nine-lever probe) solved the identity problem that had silently shaped a year of faceless aesthetics; MORNING STAR became the first film designed cast-first, battle-forward, witness-framed, triple-product; and the RIG-CONTINUUM gave the machine a self-narrating demo reel that immediately convicted two render bugs. Fable's specific fingerprints — the things a cheaper model would likely not have originated — are: the tokens-unbundle thesis, the continuation-grammar diagnosis (PSNR-measured), the witness-protagonist synthesis that kept both moats, the casting protocol's six-stage shape, the law tri-tier architecture, and the verdict→law-same-session flywheel discipline itself. All of it is now in files. That was the point.

## PART II — THE v2 MACHINE, AS BUILT (read this instead of the code)

**Layout.** `shared/v2/` holds the nine files (ingest.py, render.py, db.py + migrations/, audio.py, measure.py, visuals.py, assemble.py, upload.py, plus the schema). `v2-PLUMBING.md §4` is the per-file teardown; §6 is the decommission record (what died and the attic rule); §8 the permanent ban list. Each project: `<channel>/projects/<slug>/` containing `<slug>.db`, `stills/`, `clips/`, `work/`, `music/`, `final_video.mp4`.

**The door (ingest.py).** `python shared/v2/ingest.py --src <src-dir> --db <proj>/<slug>.db --slug <slug> --channel <ch> --title "..." --tags "..."`. Reads the src set, creates/migrates the db (auto-migration runner self-migrates older DBs — 0002 added speaking_rate/category), stamps voice/rate/category from **channel.json** (the config-drift killer: the door-read is the only config path), builds the `main` EDL over all beats, and prints the three verification lines every ceremony checks: `kling placement column: N beats (front-N kling_count IGNORED)` / migration line if any / `voice=<V> rate=<R> category=<C>`. Front-N is DEAD as a mechanism; it survives only as a fallback for column-less CSVs.

**The six stages (render.py), strict order, and why the order IS the design:** 1 **audio** (Inworld, chunked `_voice_part_NN.mp3` → concat `voiceover.mp3`); 2 **measure** (Whisper: per-beat `audio_start`/`audio_duration`/`word_timestamps` — the ground truth everything downstream obeys); 3 **visuals** (Pass A stills where `still_path IS NULL` — pre-filled paths are the provided-stills door, $0; Pass B clips where `clip_path IS NULL` — kling beats call fal then fit-to-duration, floor beats run `_kb_still`); 4–5 **attach + music** (assemble.py: concat by EDL, pin to voice length, music bed from `<project>/music/` — empty folder = graceful voice-only, the folder IS the option — sidechain ducking live); 6 **upload** (private draft, video_id set; **the upload stage does not re-fire once done** — a corrected master lands on the box as final_video.mp4 and must be pulled/uploaded manually or the stage reset deliberately). `render.py --project <dir>` with no --stage runs all six; `--stage X` runs one; **idempotent resume = rerun the same line** — every stage skips done work by NULL-checks and done-markers.

**Ceremony grammar (all banked, all receipted):** launches ride tmux with `bash -lc`, venv + `set -a && source .env && set +a`, and **`python -u`** (Law 31 rider: block-buffering once hid a healthy render behind an empty log). Monitor = `--status` (the truth) + `tail` the log. Ffmpeg-heavy renders run ONE at a time; multi-film batches chain sequentially inside one tmux (`render A && render B && …`). **Never restart mission-control mid-render** (cgroup teardown kills the animate leg). Handoffs are generated **line-by-line against the checklist** (Law 31 — the musicless flagship is the receipt for composing from memory) and delivered as ONE complete block (Law 15).

**Reset patterns (the surgical re-render toolkit):** re-render specific beats = `UPDATE beats SET clip_path=NULL WHERE …` (+ `still_path=NULL` if the frame itself must regenerate) then rerun the stage; re-assemble = `UPDATE project SET final_video_path=NULL` then `--stage attach`; floor beats re-render **free** (pure ffmpeg), kling beats re-buy the fal call. **SCHEMA TRAP, paid once:** the CSV's `kling` column ingests as **`method`** ('kling'/'floor') — resets use `WHERE method != 'kling'`, never `kling`. Full beats columns (verified live 3 Aug): id, block_id, clip_index, narration, phenomenon, subject, weight, topic_class, scale, move, method, motion_prompt, voice, image_model, video_model, audio_start, audio_duration, word_timestamps, still_path, clip_path, clip_audio, start_frame_source, end_frame_path, resolution, status, updated_at. **Work-cache law (paid once, 3 Aug):** derived intermediates in `work/` must carry version/params in their filenames or a param change silently reuses stale artifacts (the invisible-speckles cache bug; field is now `speckles_field_v3.png` with stale-purge).

**EDL (the multi-product organ).** Every ingest builds edl `main` over all beats. A second EDL = a second cut of the same master at zero render cost — this is Morning Star's Option C mechanism (feature cut + extended edition + feeders from ONE authored beat-set) and the schema anticipated it before the need existed ("anticipate in the schema, never in the code").

**Backlog (schema-anticipated, unbuilt, each = migration + code):** multi-clip chaining (`chain_count` — clip N's last frame seeds clip N+1; the only continuum point not yet data), the @-resolver (spec'd, next build), kling-tail probe flag, plus the v2-PLUMBING §7 list. **Known standing defect:** `select_thumbnail_still` leg exits 1 every run (chambers + worry shipped without it) — fix/disable cleanly, backlog.
