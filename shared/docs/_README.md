# README — The Production Doc Set (the map)

*Start here. The whole operation is now described in **two living documents** — the multi-doc set this README used to navigate has collapsed, because Mission Control closed the terminal era and the rest split cleanly into system vs. craft.*

## The two docs

1. **`_YOUTUBE-MEDIA-FLYWHEEL-canonical-reference.md` — the system.** Strategy, the channel-agnostic machine, Mission Control (the operator console), the tech stack, infra + the strict laptop→GitHub→box workflow, current state, the backlog, and the surviving box commands. **Load this first, every session.**

2. **`_ante-machinam.md` — the craft.** How to author a script worth feeding the machine: the Constitution (what the machine enforces), the VISUAL-line patterns (clean stills, drift-safe motion), the full retention canon (Part IV) with its pre-lock audit table, and the per-channel briefs. **Load this when authoring** — before you pick a topic or write a line.

## How to start a chat

Upload both, then one sentence on where you are: *"Sacred Dawn, episode two, from topic selection"* / *"Esther, stills rendered, going into review."* That collapses the surface to the relevant section. Production work needs both; pure-strategy or infra chats often need only the canonical.

`machina.md`, `PIPELINE_PLAYBOOK.md`, and `script-craft-principles.md` are stubs. Their operational content was absorbed into the canonical reference §5; their craft content into ante-machinam. Don't add to them — add system lessons to the canonical, craft lessons to ante-machinam.
